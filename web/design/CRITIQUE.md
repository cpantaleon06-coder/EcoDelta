# Design critique (before v2)

1. Palatino-style serif with system sans reads like a 2010 blog, not an instrument.
2. Every block is a white box with a grey outline, so cards, tiles and panels flatten into one weight.
3. The black left edge on selected rows and choice cards is the only accent, and it feels heavy.
4. No button hierarchy: Globe view, Back, Surprise me and Next all share one pill style.
5. The map is a sea of beige faded cells; the ranking has no graphic at all, only text.
6. Big numbers are set in the serif and do not read as measurements.
7. The detail view is text heavy: four equal tiles and long paragraphs with nothing to scan.
8. Headline and intro look like a document page, not a product.
9. Color carries almost no meaning: variables have no identity, red/blue only in arrows.
10. Spacing is generous but uniform, so the eye has no entry point.
